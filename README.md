# Football

Ton équipe de foot comme l'appli NBA : prochain match, forme, résultats et calendrier, les matchs du jour, les classements et les feuilles de match (données ESPN).

Choisis ton équipe avec l'étoile ☆ (dans MATCHS ou CLASSEMENT) : l'onglet MON ÉQUIPE montre son prochain match, sa forme, ses derniers résultats et son calendrier, coupes d'Europe comprises. Championnats : Ligue 1, Premier League, LaLiga, Serie A, Bundesliga, Ligue 2, Liga Portugal, Eredivisie, Ligue des champions, Ligue Europa. Les matchs de ton équipe peuvent aller dans ton emploi du temps.

Ses données (réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Football → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
